# Triangle Checker
A brief program that verifies whether a triangle is scalene, isosceles or equilateral.

## Author
Susan Laime Lucero

## Prerequisites
You need a C++ compiler (e.g. `g++`) installed on your system.

## Installation
Clone this repository locally in your computer. 


```bash
# SSH 
git clone git@github.com:SusanLaime/Triangle-Checker.git
cd 'Practice 1'

# HTTPS
git clone https://github.com/SusanLaime/Triangle-Checker.git
cd 'Practice 1'
```
## Usage
Run the app:

- Compile the program and execute. <br>
Note: Make sure you are in the directory of the project.

```bash
g++ triangleChecker.cpp -o triangleChecker
./triangleChecker
```

## Example output
```bash
Practice 1$ ./triangleChecker
Insert side A of the triangle: 5
Insert side B of the triangle: 5
Insert side C of the triangle: 3
TRIANGLE IS ISOSCELES
```

## Features
- Accepts float numbers.
- It works with negative numbers (to improve).
